Bench Console

Plug a Dogtooth board into this computer over USB, and this page shows what it reports, live. I use it on the bench to check the GPS and radio before a flight.

  • It works in Chrome or Edge on a desktop or laptop.
  • Only one program can use the serial port at a time. Close any serial monitor first, like the one in the Arduino IDE or PlatformIO.
  • Everything stays in this tab. Nothing is uploaded, and the data is gone when you close the page unless you save it.

This browser can't open serial ports. The Bench Console needs the Web Serial API, which Chrome and Edge have on desktops and laptops. Open this page in one of those to connect a board.

    What the board needs to send

    The board prints a block of readings once per second, like this one.

    ==================== HEARTBEAT #65 | TIME RUNNING: 1 min 5.3 s ====================

GPS
  TARGET LOCK [GPS]: ------------------ LOCKED
  CONNECTED SATELLITES: --------------- 11
  LOCK QUALITY: ----------------------- 100 % (HDOP 0.99)
  LATITUDE: --------------------------- 42.3386255
  LONGITUDE: -------------------------- -71.0896268
  ALTITUDE: --------------------------- 17.3 m
  GPS DATA RATE: ---------------------- GOOD 723 char/s
  CORRUPTED DATA OCCURRENCES (GPS): --- 1

GPS MOTION MODEL
  PORTABLE: --------------------------- OFF
  AUTOMOTIVE: ------------------------- OFF
  AIRBORNE 4G: ------------------------ ON
  OTHER: ------------------------------ OFF

RADIO
  RADIO PACKETS SENT: ----------------- 65
  RADIO PACKETS SKIPPED: -------------- 0
  RADIO PACKET ERROR OCCURRENCES: ----- 0

    The line of ==== starts a new block, and the page reads the heartbeat number and the running time from it. A line with no colon is a section name. Every other line is a label, a row of dashes and a value. The page finds each reading by its label, so the order doesn't matter and the board can leave readings out. It skips labels it doesn't know.

    A block ends at the next ==== line or at the blank line after the RADIO section. If the heartbeat number skips ahead, the page adds the missing blocks to Lost blocks. The last heartbeat turns red when no new block has come in for 3 seconds.

    A line that starts with Error: shows up in the errors box. Every other line still goes in the raw output.
